📱 Projeto React Native - Expo Sensors & Linking

um aplicativo simples em React Native desenvolvido com Expo para demonstrar o uso de sensores nativos (acelerômetro), simulação de busca por dispositivos Bluetooth e integração externa via Deep Linking (abertura do WhatsApp).
 
Funcionalidades

 Acelerômetro (Sensor): Leitura em tempo real dos eixos $X$, $Y$ e $Z$ do dispositivo.
 Simulação Bluetooth: Exibição de uma lista simulada (mock) de dispositivos Bluetooth disponíveis.
 Compartilhamento via WhatsApp: Botão que redireciona o usuário para o WhatsApp com uma mensagem pré-definida via URL scheme.
 
Tecnologias Utilizadas

 React Native Expo 
 expo-sensors (para leitura do Acelerômetro)
 
Pré-requisitos
 Antes de começar, você precisará ter instalado em sua máquina:
    Node.js
    Aplicativo Expo Go no celular (Android) para testar o app nativamente.
